# 🏁 המירוץ למיליון — אימפריית כהן

מסורת של 20+ שנה שמתקיימת מדי יום העצמאות, עם זינוק וסיום בבית של סבא וסבתא ז״ל.

## 🎯 תמצית

- **מי משתמש:** ~40 בני משפחה בגילאי 3 עד 70+, מחולקים ל~6 קבוצות (משתנה משנה לשנה)
- **מי מנהל:** "מנהלים תורנים" — מתחלפים כל שנה, עם הרשאות מלאות רק על המירוץ שלהם.
  את המשתתפים הם מוסיפים מרשימת משתמשי האתר (או בהקלדה) ומשייכים לקבוצות ידנית,
  כולל בחירה מרובה
- **איפה:** דרום הארץ — שדות נגב, נתיבות, ומקומות עם משמעות למשפחה ולשורשים
- **איך נכנסים:** התחברות Google **או הרשמה קלילה** (טלפון, שם מלא, סיסמה) ←
  קוד משחק (בסגנון Kahoot) ← קוד קבוצה ← אישור מנהל
- **מה קורה במירוץ:** כל קבוצה מתקדמת בין תחנות; משימה נפתחת רק בהגעה פיזית לנקודה (GPS),
  צ'אט קבוצתי, טבלת מובילים חיה, וספירה לאחור גדולה למירוץ הקרוב
- **הנשמה:** בית משפחתי לכל השנה — צפייה במירוץ החי ובמירוצי העבר, משפטים של
  סבא וסבתא, קריקטורות, גלריית תמונות, היכל התהילה של זוכי כל השנים
- **עלות ופלטפורמה:** אתר בלבד, בלי הורדה מחנות אפליקציות; אירוח בחינם —
  מתאים לאירוע של פעם בשנה
