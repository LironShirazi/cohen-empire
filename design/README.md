# 🎨 מערכת העיצוב — המירוץ למיליון

מקור מערכת העיצוב של האפליקציה. מסונכרנת לפרויקט **Claude Design** בשם
"המירוץ למיליון — מערכת עיצוב" ב-[claude.ai/design](https://claude.ai/design)
(projectId: `08a89147-2089-4a4c-b7e0-c115b18a7af5`).

- `build_ds.py` — סקריפט שמייצר את כל קבצי ה-HTML (טוקנים משותפים + רכיבים).
  לעריכה: משנים בסקריפט, מריצים `python3 build_ds.py`, ומסנכרנים מחדש עם DesignSync
- `foundations/` — צבעים (מותג + 6 צבעי קבוצות) וטיפוגרפיה עברית
- `components/` — רכיבי RTL: כפתורים, התחברות/קודים, ספירה לאחור, ציטוטי סבא וסבתא,
  כרטיס קבוצה, לידרבורד, רמז/משימה, צ'אט, היכל התהילה, ניהול משתתפים

עקרונות: חם ומשפחתי, עברית RTL מלאה, טקסט וכפתורים גדולים לגילאי 3 עד 70+,
צבע+חיה כזהות קבוצה בכל מסך.
