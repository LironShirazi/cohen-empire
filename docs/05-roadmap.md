# 05 — תוכנית פיתוח

עיקרון מנחה: יש דדליין טבעי — **יום העצמאות**. בונים בשלבים כך שבכל רגע יש
מוצר שמישהו יכול לשחק בו, ומשאירים זמן ל**מירוץ ניסיון** משפחתי קטן לפני היום הגדול.

## שלב 0 — תשתית
- הקמת פרויקט Next.js + TypeScript + Tailwind (RTL)
- חיבור Supabase: Auth עם Google, סכמת DB ראשונית, RLS בסיסי
- פריסה ל-Vercel + דומיין
- שלד עיצוב: ערכת נושא, פונט עברי, קומפוננטות בסיס

## שלב 1 — MVP: אפשר לשחק מירוץ 🎯
- דף בית עם **ספירה לאחור** למירוץ הקרוב
- מנהל תורן: יצירת מירוץ (קוד משחק), יצירת קבוצות (שם/צבע/חיה/קוד), יצירת תחנות
  עם מיקום על מפה + רדיוס, סדר תחנות (זהה/אקראי/ידני פר-קבוצה)
- זרימת כניסה: Google ← קוד משחק ← קוד קבוצה ← המתנה ← אישור מנהל
- מסך קבוצה: **מהלך המשחק** — רמז ← נעילת GPS ← פתיחת משימה ← השלמה ← תחנה הבאה
- אימות מרחק בצד שרת + כפתור עקיפה למנהל
- לידרבורד חי (דירוג בלבד)
- סיום מירוץ, הכרזת זוכים, ארכוב

## שלב 2 — צ'אט וכלי ניהול חיים 💬
- ✅ **צ'אט קבוצתי בזמן אמת + צירוף קבצים מכל סוג** — כולל הצ'אט של המנהל
  עם כל קבוצה. ההרשאות ב-RLS (`0005_phase2_chat.sql`), הפרטים ומה שנשאר
  פתוח ב-CLAUDE.md §7
- ✅ **אזכורים (@) בצ'אט + התראות In-App** — בורר במחבר, באנר קופץ מעל כל
  מסך, באדג' `@` על כפתור הצ'אט, וקפיצה להודעה המאזכרת. ההתראה נוצרת
  בטריגר DB בלבד (`0006_phase2_mentions.sql`)
- ✅ **מנהל: תור אישורי משימות** (כולל תמונות) **+ הודעות רוחב** — הודעת
  המנהל נכנסת לצ'אט של כל קבוצות היעד ומקפיצה באנר אצל המשתתפים
  (`0007_phase2_broadcast.sql`)
- ✅ **מפת מנהל חיה עם מיקומי קבוצות** — דיווח מיקום ממסך המשחק,
  שורה אחת לקבוצה, קריאה למנהל בלבד (`0008_phase2_live_map.sql`)
- ✅ **הוספת משתתפים ידניים לקבוצה** (ילדים ללא טלפון) — `user_id is null`
  ב-`team_members`, עם RLS שמגביל את העריכה לשורות הידניות בלבד
  (`0009_phase2_manual_members.sql`)

## שלב 3 — הנשמה המשפחתית ❤️
- ✅ **העץ המשפחתי** — כבר ממומש כמודול עצמאי (`family-tree/`);
  בשלב זה מחברים אותו ל-Supabase (טבלת `family_members`, Storage, Realtime)
  ולזרימת "אני בעץ" אחרי התחברות Google — ראו [06](06-family-tree.md)
- משפטי סבא וסבתא + תמונות/קריקטורות משולבים באפליקציה
- היכל התהילה + הזנת 20 שנות היסטוריה
- ✅ **גלריית מדיה משפחתית** — אלבומים בשם חופשי (לא רק מירוצים), תמונות
  וסרטונים, העלאה ועריכת שם ע"י כל בן משפחה; מיגרציות `0012`+`0013`
- ליטוש: אנימציות, PWA להתקנה על מסך הבית, מסך זוכים חגיגי

## שלב 4 — עתידי 🚀
