# 04 — מסכים וחוויית משתמש

עברית מלאה, RTL, Mobile-First. שפה עיצובית חמה ומשפחתית — לא "אפליקציית משרד":
צבעי קבוצות בולטים, אימוג'י חיות, תמונות/קריקטורות של סבא וסבתא משולבות לאורך הדרך.

## 1. מסכים ציבוריים (לפני/אחרי מירוץ)

### 🏠 דף הבית
- **ספירה לאחור גדולה, בולטת ויפה** למירוץ הקרוב (ימים : שעות : דקות : שניות)
- כפתור ראשי: "כניסה למשחק" (כשהמשחק פתוח)
- ציטוט מתחלף של סבא/סבתא עם התמונה/קריקטורה שלהם
- קישורים: היכל התהילה, גלריה, **העץ המשפחתי**, הקבוצות שלי

### 🌳 העץ המשפחתי
- כפתור קבוע בדף הבית לצד הגלריה, ללא קשר למהלך המשחק — ראו
  [06 — העץ המשפחתי](06-family-tree.md)
- עיגולים עם שם + תמונה + שנת לידה; סבא אורגני ראובן וסבתא טראקי במרכז
- מצב עריכה להוספת אבא ואמא / בנים / בני זוג לכל עלה; תצוגה מוגדלת
  (כולל טלפון) ועריכת עלה; "אני בעץ" אחרי הרשמה; ייצוא PNG/PDF

### 🏆 היכל התהילה
- טבלת זוכי כל השנים (כולל 20 שנות היסטוריה שיוזנו ידנית)
- שנה, שם קבוצה + צבע + חיה, חברי הקבוצה, תמונת הזוכים
- סטטיסטיקות משעשעות: שיאן ההשתתפויות, שיאן הזכיות...

### 📸 גלריה
- תמונות לפי שנים, העלאה ע"י כל משתתף, ניהול (מחיקה/כותרות) ע"י מנהלים

## 2. זרימת כניסה למשחק

```
התחברות Google ← הזנת קוד משחק ← הזנת קוד קבוצה ← "ממתין לאישור המנהל..." ← אושר? ← מסך הקבוצה
```

- מסך ההמתנה מציג את שם הקבוצה, הצבע והחיה + ציטוט סבא/סבתא להנעמת ההמתנה
- דחייה מציגה הודעה ומאפשרת ניסיון עם קוד קבוצה אחר

## 3. מסך הקבוצה (המסך המרכזי במירוץ)

כותרת: שם קבוצה + צבע + חיה. מתחתיה **שני כפתורים גדולים**:

### ▶️ מהלך המשחק
- **לפני הגעה לתחנה:** הרמז/החידה שמובילה למקום + מד מרחק חי ("עוד 340 מ׳ 🔥")
  — בלי לחשוף את המשימה עצמה
- **בתוך הרדיוס:** אנימציית פתיחה 🎉 והמשימה נחשפת (טקסט/תמונה/וידאו + סיפור הרקע של המקום)
- **השלמה** לפי סוג התחנה: הזנת קוד סודי / צילום והעלאה / המתנה לאישור מנהל
- **אחרי השלמה:** מעבר אוטומטי לרמז של התחנה הבאה
- **בסיום כל התחנות:** "חזרו לבית סבא! 🏁"

### 💬 צ'אט קבוצתי
- כל חברי הקבוצה + המנהל התורן
- טקסט + צירוף קבצים מכל סוג (מצלמה ישירות, גלריה, קול)
- **אזכורים (@) כמו בווצאפ:** הקלדת `@` פותחת בורר נגלל מעל המקלדת —
  חברי הקבוצה + המנהל התורן (מסומן 👑), מסתנן תוך כדי הקלדה;
  האזכור מוצג מודגש בצבע הקבוצה בגוף ההודעה
- (עתידי) כפתור שיחה קולית קבוצתית

וגם: 🏅 לידרבורד חי (דירוג בלבד — בלי "משימה 3 מתוך 7"), 👥 צפייה בכל הקבוצות והרכבן.

### 🔔 התראות אזכור — איפה הן מופיעות

העיקרון: במהלך מירוץ אף אחד לא יושב בצ'אט — כולם במסך "מהלך המשחק" או עם
הטלפון בכיס. לכן ההתראה בנויה בשלוש שכבות, מהרגעי למתמיד:

1. **באנר קופץ בראש המסך (בכל מסך):** "יואב מהכחולים 🐬 תייג אותך: מצאנו את ה...",
   נעלם לבד אחרי ~5 שניות. הקשה עליו קופצת ישר להודעה בצ'אט. לא מודאל —
   לא חוסם משימה באמצע
2. **באדג' `@` על כפתור הצ'אט** במסך הקבוצה (בסגנון ה-@ הירוק של ווצאפ,
   נבדל ממונה הודעות רגיל) — נשאר דלוק עד שקוראים
3. **בפתיחת הצ'אט:** גלילה אוטומטית להודעה המאזכרת + הבהוב הדגשה שלה;
   מי שלא היה מחובר בזמן האזכור רואה את זה בכניסה הבאה

## 4. מסכי ניהול (מנהל תורן בלבד)

### לוח בקרה של המירוץ
- סטטוס: `draft ← open ← live ← finished`
- קוד המשחק מוצג בענק לשיתוף
- בקשות הצטרפות ממתינות עם אישור/דחייה בהקשה

### ניהול תחנות
- רשימה + מפה של כל התחנות
- הוספה/עריכה: שם, סיפור רקע, רמז, משימה, **בחירת מיקום על מפה + רדיוס**, סוג השלמה
- קביעת סדר: זהה לכולם / אקראי לכל קבוצה / גרירה ידנית פר-קבוצה

### ניהול קבוצות
- יצירה: שם, צבע (בורר צבעים), חיה (בורר אימוג'י), קוד קבוצה
- הרכבת הקבוצות ידנית — אין "חלוקה אוטומטית" (בוטל, ראו [02](02-architecture.md) §3.6)
- הוספת משתתפים ידניים (ילדים ללא טלפון): שם + שנת לידה (רשות)

### מהלך המירוץ (Live)
- מפה עם מיקום אחרון של כל קבוצה + באיזו תחנה כל קבוצה נמצאת (למנהל כן רואים הכל)
- תור אישורי משימות (תמונות שהועלו / בקשות אישור)
- כפתור "פתח משימה ידנית" לתקלות GPS
- שליחת הודעה לכל הקבוצות או לקבוצה ספציפית
- סיום מירוץ ← הכרזת זוכים ← ארכוב (נעילת עריכה) + הוספה אוטומטית להיכל התהילה

## 5. ניהול תוכן (מנהל-על)
- משפטי סבא וסבתא + העלאת תמונות/קריקטורות
- עריכת היכל התהילה ההיסטורי
- מינוי מנהלים תורנים למירוץ החדש
